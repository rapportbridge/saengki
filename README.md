# 온결의원 실습 홈페이지

가상의 병원 정보를 살펴보고 건강 정보 글을 작성해 보는 연습용 홈페이지입니다. 실제 진료 정보가 아닙니다.

## 사용 방법

- `index.html`을 열어 홈페이지를 확인하세요.
- ‘검색 정보 직접 바꿔보기’에서 병원 정보를 바꿀 수 있습니다. 입력한 내용은 사용 중인 브라우저에만 저장됩니다.
- ‘건강 정보 글 작성하기’에서 글을 작성하고 파일로 저장할 수 있습니다. 저장한 글은 홈페이지에 자동으로 게시되지 않습니다.
- 수정한 홈페이지 파일을 저장하면 입력한 정보가 파일에 포함됩니다. 공개 전에 내용을 확인하세요.

## GitHub Pages에 올리기

이 폴더의 파일을 저장소에 올리고, 저장소의 Settings → Pages에서 배포할 브랜치와 루트 폴더를 선택하세요.
